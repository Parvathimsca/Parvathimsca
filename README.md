## 🚀 Featured Project

<div align="center">

# 🧠 Moyamoya Detection

### Automated Diagnosis of Moyamoya Disease from Brain MRI Using Convolutional Neural Networks (CNNs)

</div>

My final-year project focuses on using **deep learning and computer vision** to assist in the detection of Moyamoya disease from brain MRI images.

The system uses a CNN-based approach to classify MRI images into **Moyamoya** and **Normal** categories.

```text
🧠 Brain MRI
      ↓
🖼️ Image Preprocessing
      ↓
🤖 CNN / EfficientNet
      ↓
🔍 Feature Extraction
      ↓
🧠 Moyamoya Classification
      ↓
📊 Prediction & Evaluation
```

**Technologies:**

`Python` `TensorFlow` `Keras` `CNN` `EfficientNet` `Computer Vision` `Machine Learning`
